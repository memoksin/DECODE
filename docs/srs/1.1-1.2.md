## 1.1 Purpose

In remote technical interviews, interviewers can only judge a candidate's programming experience from the candidate's own statements and the final code, not from how the candidate reads and understands code. DECODE aims to classify a candidate as a novice or experienced programmer during a videoconference interview by comparing their webcam-based gaze sequence with Scanpath Trend Analysis (STA) trending paths of each group. Eye movements show how programmers read code, and STA has been used to compare groups of programmers [4], but it has not yet been used to predict the experience level of an individual programmer, so DECODE can give interviewers additional, objective insight.

## 1.2 Scope

DECODE supports remote technical interviews with an eye-tracking-based estimate of a candidate's programming experience.

**Goals**

- Make it possible to estimate programming experience remotely during technical interviews.
- Show whether STA trending paths can predict the experience level of an individual programmer.
- Give interviewers additional insight that supports, but does not replace, their decision.
- Protect candidates' privacy while their gaze is analysed.

**Objectives**

- Review the literature on classifying programmers by experience with eye-tracking data.
- Select a public eye-tracking dataset with experience labels and generate individual scanpaths from it.
- Apply STA to these scanpaths to produce trending paths for novice and experienced programmers.
- Develop a videoconferencing extension that estimates where the candidate looks on the shared code, builds their scanpath and classifies it against both trending paths.
- Evaluate the classification with accuracy, precision and recall on held-out participants.

**Limitations**

- Only two classes (novice / experienced), since binary classification performs better than three levels [3].
- Only code reading on the shared screen is analysed. Typing and writing behaviour are not modelled.
- Webcam gaze is less accurate than an eye tracker, so areas of interest may need to be code blocks instead of single lines.
- Trending paths depend on the code shown in the public dataset and may not transfer to other code.
- Only Google Meet is supported. It was chosen because a browser extension can read the meeting video directly, with no paid API or app approval.
